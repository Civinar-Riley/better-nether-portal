# 1.1.0 优化验证

Instabox：Linux、Java 21、4 vCPU / 8 GiB。基线为已发布的 `v1.0.2`（`2b6f308`），优化版包含建门事件、操作栏提示与落点搜索分配优化。

## 功能

- 点火、复制门、普通矩形回退及强制平台回退均在首次写方块前发送 `PortalCreateEvent`。
- 事件继承 `BlockEvent.PortalSpawnEvent`；既有父事件监听器可取消，取消后不继续回退创建。
- 事件提供不可变的实际门格集合及完整拟写入计划，包含框架、支撑和净空清理。
- 玩家传送失败时显示中英文操作栏提示，每人最多每 100 tick 提示一次。
- 净空及支撑偏移在蓝图构造时计算；候选搜索复用位置游标，保留地面、空中、开凿的原有顺序。

## 性能对照

同一机器依次执行两个版本。区块预加载、场地布置、门形捕获和恢复均不计时；每组合 3 次预热、5 次测量，取中位数。计时覆盖公开 `placeNear` 的搜索与实际放置；优化版计时也包含新增事件和写入计划开销。每轮断言返回的相对门根不变。

| 场景 | 门内部格数 | 1.0.2 耗时 | 1.1.0 耗时 | 1.0.2 分配 | 1.1.0 分配 | 分配减少 |
|---|---:|---:|---:|---:|---:|---:|
| 前 48 个空中候选被环境阻挡，第 49 个成功 | 64 | 6.037 ms | 2.347 ms | 2,678,520 B | 128,496 B | 95.2% |
| 地面及空中均失败，首个开凿候选成功 | 64 | 17.465 ms | 12.547 ms | 5,565,256 B | 2,020,760 B | 63.7% |
| 前 48 个空中候选被环境阻挡，第 49 个成功 | 441 | 7.851 ms | 4.140 ms | 8,239,712 B | 642,408 B | 92.2% |
| 地面及空中均失败，首个开凿候选成功 | 441 | 10.012 ms | 10.786 ms | 6,777,384 B | 1,451,520 B | 78.6% |

两个场景的落点分别为目标点相对 `(0, -23, 0)` 和 `(0, 1, 0)`，两个版本全部一致。候选连续被拒绝的场景耗时减少约 47%–61%；441 格开凿场景耗时增加约 7.7%，分配显著减少。该结果来自短时合成基准，不能等同于所有地形或整合包的性能。

## 回归

`bash gradlew build runGameTestServer --no-daemon`：33 个 GameTest 全部通过，服务器保存世界并正常退出。新增用例验证父事件取消、取消无写入、复制不回退、原版两种回退分支、完整写入计划、操作栏和提示节流。

## 限制

尚未进行客户端画面或具体领地模组整合测试。父事件兼容及取消行为已通过服务端 GameTest 验证；若保护模组需检查整扇门的范围，应使用 `getPlannedBlocks()`。基准不包含网络、区块生成或首次依赖加载。
